INForensis Technologies Website Template

CONTENTS
- index.html: main responsive website
- assets/css/styles.css: styles and responsive layout
- assets/js/main.js: mobile navigation and client-logo slideshow
- assets/images/inforensis-logo.png: supplied Inforensis Technologies logo
- fontawesome-5.5/: icons used by the template

PREVIEW
Open index.html in a modern browser. An internet connection is required for the Google Fonts and SyrupsBiz-hosted customer logo images.

BEFORE PUBLISHING
1. Replace YOUR-EMAIL@example.com in index.html with Inforensis Technologies' official email address.
2. The client logo slideshow currently references the five image files published on https://www.syrupsbiz.com/assets/img/clients/ (c1.jpg, c2.jpg, c3.jpg, c4.jpg, c5.png). The slideshow needs internet access to load them. For reliable production hosting, download the logos only after confirming permission, place them in assets/images/clients/, and update their src paths to local files.
3. These logos are labelled as references from SyrupsBiz's public website. Confirm permission and the relationship with Inforensis Technologies before representing them as Inforensis customers.
4. Review all solution/service descriptions and contact details before launch.
5. This is a static front-end website. There is no backend contact form or CMS.

The listed solution categories and services are based on the publicly accessible SyrupsBiz website as reviewed on 14 October 2026.
